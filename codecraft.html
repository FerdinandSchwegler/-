Modul 1 · Lektion 1

Was ist Programmieren?

Programmieren bedeutet, einem Computer in einer Sprache, die er versteht, präzise Anweisungen zu geben. In dieser Lektion lernst du, was dahinter steckt — ohne Fachchinesisch.

Der Computer: mächtig, aber ohne Eigeninitiative

Ein Computer kann nichts, was man ihm nicht explizit beibringt. Er ist schnell, präzise und unermüdlich — aber von Natur aus vollkommen passiv. Damit er etwas tut, braucht er Anweisungen in einer exakten, formalen Sprache.

Diese Sprache nennen wir Programmiersprache. Sie ist der Vertrag zwischen deinem Denken und der Ausführung des Computers.

🎯
Analogie
Programmieren ist wie Kochen nach Rezept. Das Rezept (dein Code) beschreibt jeden Schritt exakt. Der Koch (der Computer) führt ihn buchstabengetreu aus. Fehlt ein Schritt oder ist er falsch — gelingt das Gericht nicht.

Wie Programmierung funktioniert

Du schreibst lesbaren Text — Code — in einer definierten Syntax. Ein Programm namens Interpreter oder Compiler übersetzt diesen Text in Befehle, die der Prozessor versteht.

  • Python ist eine interpretierte Sprache: Der Interpreter liest deinen Code Zeile für Zeile und führt ihn sofort aus.
  • HTML ist keine klassische Programmiersprache, sondern eine Auszeichnungssprache (Markup). Der Browser interpretiert sie und stellt Webseiten dar.

Dein erstes Gedankenexperiment

Stell dir vor, du musst einem Roboter erklären, wie er eine Tasse Kaffee macht. Du müsstest jeden Schritt präzise beschreiben:

  1. Gehe zur Kaffeemaschine.
  2. Öffne den Deckel des Wassertanks.
  3. Fülle genau 300 ml Wasser ein.
  4. Schließe den Deckel.
  5. Lege eine Kapsel ein.
  6. Stelle eine Tasse unter den Auslass.
  7. Drücke den Einschaltknopf.
  8. Warte, bis das Lämpchen erlischt.

Genau so ist Programmieren. Kein Schritt darf fehlen, kein Schritt darf vage sein. Diese Präzision ist der wichtigste Unterschied zwischen menschlicher Kommunikation und Programmierung.

Was du mit Programmieren tun kannst

Nach diesem Kurs kannst du:

  • Eigene Webseiten mit HTML erstellen und im Browser anzeigen
  • Python-Programme schreiben, die Berechnungen durchführen
  • Texte verarbeiten, Dateien lesen und schreiben
  • Einfache Aufgaben automatisieren (z.B. Datei umbenennen)
  • Das Fundament legen für fortgeschrittene Themen wie Web-Backends, Datenanalyse oder KI

Modul 1 · Lektion 6

Debuggen: Fehler finden und lösen

Fehler im Code sind kein Versagen — sie sind normaler Teil des Programmierens. Jeder macht sie. Der Unterschied liegt im systematischen Umgang damit.

Die drei Fehlerarten

1. Syntaxfehler — Der Code ist grammatikalisch falsch

Python versteht den Code nicht und verweigert die Ausführung. Die Fehlermeldung enthält fast immer die Zeilennummer.

Python — Syntaxfehler
# FALSCH: fehlende schließende Klammer
print("Hallo"

# Fehlermeldung:
# SyntaxError: '(' was never closed

# RICHTIG:
print("Hallo")

2. Laufzeitfehler — Der Code läuft, stürzt aber ab

Python — Laufzeitfehler
# FALSCH: Division durch Null
ergebnis = 10 / 0
# ZeroDivisionError: division by zero

# FALSCH: String in Zahl umwandeln
zahl = int("abc")
# ValueError: invalid literal for int()

3. Logikfehler — Läuft, aber falsches Ergebnis

Python — Logikfehler
# Ziel: Durchschnitt von 3 und 7
ergebnis = 3 + 7 / 2   # Falsch! Punkt vor Strich → 3+3.5 = 6.5
print(ergebnis)         # Ausgabe: 6.5 (nicht 5.0!)

# RICHTIG: Klammern setzen
ergebnis = (3 + 7) / 2  # 5.0 ✓

Debugging-Strategie in 5 Schritten

  1. Fehlermeldung vollständig lesen — Sie enthält die Fehlerart, Dateiname und Zeilennummer
  2. Zeilennummer aufsuchen — Der Fehler ist oft eine Zeile davor oder genau dort
  3. print() als Debuggingwerkzeug — Zwischenwerte ausgeben, um zu verstehen, was der Code wirklich macht
  4. Laut vorlesen — Wenn du den Code vorliest, fallen logische Fehler oft auf
  5. Suchmaschine nutzen — Die Fehlermeldung googeln. Diese Fehler hat jeder schon gehabt.
Python — print() zum Debuggen
def berechne(a, b):
    print(f"a = {a}, b = {b}")   # Debug-Ausgabe
    ergebnis = a + b
    print(f"ergebnis = {ergebnis}")   # Debug-Ausgabe
    return ergebnis
Modul 1 · Lektion 7

Typische Anfängerfehler — und wie du sie vermeidest

Diese Liste hilft dir, die häufigsten Fehler zu kennen, bevor du sie selbst machst. Jeder dieser Fehler wurde von jedem Anfänger gemacht — du bist nicht allein.

Python-Fehler

⚠️
Fehler #1: Einrückung (IndentationError)
Python verwendet Einrückungen als Strukturelement. 4 Leerzeichen oder 1 Tab — aber nie beides mischen. Konsistenz ist zwingend.
Python
# FALSCH: fehlende Einrückung
def sag_hallo():
print("Hallo")  # IndentationError!

# RICHTIG: 4 Leerzeichen
def sag_hallo():
    print("Hallo")  # ✓
⚠️
Fehler #2: Anführungszeichen-Mismatch
Strings müssen mit denselben Anführungszeichen beginnen und enden. Einfache (') und doppelte (") sind gleichwertig — aber nicht mischbar.
Python
# FALSCH:
name = 'Anna"    # SyntaxError

# RICHTIG:
name = 'Anna'    # oder
name = "Anna"    # beides korrekt
⚠️
Fehler #3: Groß-/Kleinschreibung bei Variablen
Python ist case-sensitive. Name und name sind zwei verschiedene Variablen!
Python
Alter = 25
print(alter)   # NameError: name 'alter' is not defined!
print(Alter)   # 25 ✓
⚠️
Fehler #4: input() liefert immer einen String
Selbst wenn der Nutzer eine Zahl eingibt — input() gibt immer Text zurück. Für Rechnungen muss konvertiert werden.
Python
# FALSCH: TypeError bei Rechnung
alter = input("Alter: ")
geburtsjahr = 2024 - alter   # TypeError: int - str

# RICHTIG: Konvertierung zu int
alter = int(input("Alter: "))
geburtsjahr = 2024 - alter   # ✓

HTML-Fehler

⚠️
Fehler #5: Tags nicht geschlossen
Jeder öffnende Tag braucht einen schließenden Tag — außer "void elements" wie <br>, <img>, <input>.
HTML
<!-- FALSCH -->
<p>Text ohne schließenden Tag
<p>Zweiter Absatz

<!-- RICHTIG -->
<p>Text mit schließendem Tag</p>
<p>Zweiter Absatz</p>
⚠️
Fehler #6: Falsche Verschachtelung
Tags müssen in der Reihenfolge ihres Öffnens wieder geschlossen werden — wie Klammern in der Mathematik.
HTML
<!-- FALSCH -->
<b><i>Text</b></i>

<!-- RICHTIG -->
<b><i>Text</i></b>

Variablen & Datentypen

Variablen sind benannte Speicherplätze. Datentypen definieren, welche Art von Wert darin steckt. Beides ist das Herzstück jedes Programms.

Was ist eine Variable?

Stelle dir eine Variable wie eine beschriftete Schachtel vor. Du legst einen Wert hinein, gibst der Schachtel einen Namen, und kannst sie später aufmachen, um den Wert zu lesen oder zu verändern.

Python
# Variable erstellen (zuweisen)
name = "Anna"
alter = 28
groesse = 1.72
aktiv = True

# Variable lesen
print(name)    # Anna
print(alter)   # 28

# Variable verändern
alter = 29
print(alter)   # 29

Regeln für Variablennamen

  • Darf Buchstaben, Zahlen und Unterstriche enthalten: mein_name_1
  • Muss mit Buchstabe oder Unterstrich beginnen: _privat ✓, 1name ✗
  • Keine Python-Schlüsselwörter: if, for, class, return etc. sind reserviert
  • Konvention: snake_case — alles klein, Wörter mit Unterstrich trennen: mein_name, max_wert
✨
Gute Namen sparen Zeit
x oder temp sind kryptisch. benutzername, gesamtpreis, max_versuche erklären sich selbst. Guter Code liest sich wie Prosa.

Die wichtigsten Datentypen

Python — Alle Grundtypen
# int — ganze Zahlen

anzahl = -3
bevoelkerung = 8_000_000   # _ für Lesbarkeit erlaubt

# float — Dezimalzahlen

# str — Zeichenketten (Strings)

Zeile 3"""

# bool — Wahrheitswerte

# Typ abfragen
print(type(alter))    # <class 'int'>

print(type(vorname))  # <class 'str'>

Listen, Tupel, Dictionaries

Python — Sammlungstypen

namen = ["Anna", "Max", "Lisa"]

gemischt = [1, "Text", True]

Operatoren

Operatoren verknüpfen Werte, führen Berechnungen durch und vergleichen. Sie sind die Rechenzeichen der Programmierung.

Arithmetische Operatoren

Python
a, b = 15, 4

print(a + b)    # 19  — Addition
print(a - b)    # 11  — Subtraktion
print(a * b)    # 60  — Multiplikation
print(a / b)    # 3.75 — Division (immer float)
print(a // b)   # 3   — Ganzzahldivision (abrunden)
print(a % b)    # 3   — Modulo (Rest der Division)
print(a ** b)   # 50625 — Potenz (15^4)
print(2 ** 8)   # 256  — 2 hoch 8

Vergleichsoperatoren

Vergleichsoperatoren liefern immer True oder False.

Python
x = 5

print(x == 5)   # True  — Gleichheit (DOPPELTES Gleichzeichen!)
print(x != 3)   # True  — Ungleich
print(x > 4)    # True  — Größer als
print(x < 10)   # True  — Kleiner als
print(x >= 5)   # True  — Größer oder gleich
print(x <= 4)   # False — Kleiner oder gleich
⚠️
= vs ==
Ein = weist einen Wert zu. Zwei == vergleichen. Das ist einer der häufigsten Anfängerfehler!

Logische Operatoren

Python
alter = 25
hat_ausweis = True

print(alter >= 18 and hat_ausweis)   # True — beide müssen wahr sein
print(alter < 18 or hat_ausweis)     # True — mindestens eines muss wahr sein
print(not hat_ausweis)              # False — Negation

String-Operatoren

Python
vorname = "Anna"
nachname = "Müller"

# Konkatenation (+ verbindet Strings)
vollname = vorname + " " + nachname
print(vollname)   # Anna Müller

# f-String (empfohlen — moderner und lesbarer)
print(f"Name: {vorname} {nachname}")   # Name: Anna Müller

# Wiederholung
print("Ha" * 3)   # HaHaHa

# Enthält?
print("Anna" in vollname)   # True

Bedingungen — Programme, die entscheiden

Bedingungen erlauben deinem Programm, Entscheidungen zu treffen. Genau wie im echten Leben: Wenn X, dann Y. Sonst Z.

Python — if / elif / else
alter = int(input("Wie alt bist du? "))

if alter >= 18:
    print("Volljährig — Zutritt erlaubt.")
elif alter >= 16:
    print("Fast volljährig — eingeschränkter Zutritt.")
else:
    print("Minderjährig — kein Zutritt.")

Aufbau erklärt

  • if — Startet die Bedingung. Doppelpunkt am Ende ist Pflicht. Einrückung ist Pflicht.
  • elif — Optional. Weitere Bedingung, wenn die erste falsch war. Beliebig viele möglich.
  • else — Optional. Auffangfall — läuft, wenn alle anderen Bedingungen falsch sind.

Verschachtelte Bedingungen

Python
wetter = "Regen"
hat_schirm = True

if wetter == "Regen":
    if hat_schirm:
        print("Es regnet, aber du hast einen Schirm.")
    else:
        print("Es regnet und du wirst nass!")
else:
    print("Kein Regen — genieß den Tag!")

Einzeiliger Ternär-Ausdruck

Python
alter = 20
status = "Volljährig" if alter >= 18 else "Minderjährig"
print(status)   # Volljährig

Schleifen — Code wiederholen

Schleifen sind eines der mächtigsten Konzepte in der Programmierung. Statt 100 Zeilen zu schreiben, lässt du eine Schleife 100 Mal laufen.

for-Schleife

Iteriert über eine Sequenz — Liste, String, Zahlenbereich.

Python
# Über Zahlenbereich
for i in range(5):
    print(i)          # 0, 1, 2, 3, 4

# Über eine Liste
fruechte = ["Apfel", "Banane", "Kirsche"]
for frucht in fruechte:
    print(f"Ich esse: {frucht}")

# Mit Index (enumerate)
for i, frucht in enumerate(fruechte):
    print(f"{i}: {frucht}")   # 0: Apfel, 1: Banane...

# Über String
for buchstabe in "Hallo":
    print(buchstabe)   # H, a, l, l, o

while-Schleife

Läuft so lange, wie eine Bedingung wahr ist.

Python
zahl = 1
while zahl <= 5:
    print(zahl)
    zahl += 1    # Kurzschreibweise für zahl = zahl + 1

# Endlosschleife mit break
while True:
    eingabe = input("Passwort: ")
    if eingabe == "geheim":
        print("Zugang gewährt!")
        break   # Schleife verlassen
    else:
        print("Falsch. Nochmal.")
⚠️
Endlosschleife
Eine while-Schleife, deren Bedingung nie False wird, läuft ewig und legt dein Programm lahm. Stelle sicher, dass der Abbruchzustand irgendwann erreicht wird. Notfall: Strg+C stoppt das Programm im Terminal.

break und continue

Python
for i in range(10):
    if i == 7:
        break       # Schleife sofort beenden
    if i % 2 == 0:
        continue    # Diesen Durchlauf überspringen
    print(i)        # Nur ungerade Zahlen unter 7: 1,3,5

List Comprehension — kompakte Schleifen

Python
# Klassisch
quadrate = []
for x in range(5):
    quadrate.append(x**2)

# Kompakt (List Comprehension) — pythonisch
quadrate = [x**2 for x in range(5)]
print(quadrate)   # [0, 1, 4, 9, 16]

# Mit Bedingung
gerade = [x for x in range(10) if x % 2 == 0]
print(gerade)     # [0, 2, 4, 6, 8]

Funktionen — Code wiederverwenden

Eine Funktion ist ein benannter, wiederverwendbarer Code-Block. Statt denselben Code mehrfach zu schreiben, definierst du ihn einmal und rufst ihn beliebig oft auf.

Python — Grundstruktur
def berechne_flaeche(breite, hoehe):
    """Berechnet die Fläche eines Rechtecks."""
    flaeche = breite * hoehe
    return flaeche

# Funktion aufrufen
ergebnis = berechne_flaeche(5, 3)
print(ergebnis)   # 15

# Direkt in print()
print(berechne_flaeche(10, 4))   # 40

Standardparameter (Default Values)

Python
def begruesse(name, sprache="Deutsch"):
    if sprache == "Deutsch":
        return f"Hallo, {name}!"
    elif sprache == "Englisch":
        return f"Hello, {name}!"
    else:
        return f"Hola, {name}!"

print(begruesse("Anna"))               # Hallo, Anna!
print(begruesse("John", "Englisch"))   # Hello, John!

*args und **kwargs — Flexible Argumente

Python
# *args: beliebig viele Positionalargumente
def summe(*zahlen):
    return sum(zahlen)

print(summe(1, 2, 3))       # 6
print(summe(10, 20, 30, 40))  # 100

# **kwargs: beliebig viele Schlüsselwort-Argumente
def profil(**infos):
    for key, wert in infos.items():
        print(f"{key}: {wert}")

profil(name="Anna", alter=28, stadt="Berlin")

Lambda — anonyme Einzeilerfunktionen

Python

# Nützlich für Sortierung
personen = [("Anna", 28), ("Max", 22), ("Lisa", 35)]

print(personen)   # [('Max', 22), ('Anna', 28), ('Lisa', 35)]

Klassen & Objekte

Objektorientierte Programmierung (OOP) strukturiert Code um „Objekte" — Datenstrukturen mit Eigenschaften und Fähigkeiten. Eine Klasse ist der Bauplan, ein Objekt ist das fertige Produkt.

Python — Klasse definieren
class Person:
    def __init__(self, name, alter):
        self.name = name    # Attribut
        self.alter = alter  # Attribut

    def vorstellen(self):    # Methode
        return f"Ich bin {self.name}, {self.alter} Jahre alt."

    def geburtstag(self):
        self.alter += 1
        print(f"{self.name} ist jetzt {self.alter}!")

# Objekte erstellen
person1 = Person("Anna", 28)
person2 = Person("Max", 34)

print(person1.vorstellen())   # Ich bin Anna, 28 Jahre alt.
print(person2.alter)           # 34
person1.geburtstag()           # Anna ist jetzt 29!

Vererbung

Python
class Tier:
    def __init__(self, name):
        self.name = name

    def atmen(self):

class Hund(Tier):   # Erbt von Tier

Fehlerbehandlung, Module & Best Practices

Professioneller Code stürzt nicht einfach ab — er behandelt Fehler elegant. Und guter Code ist nicht nur korrekt, sondern auch lesbar und wartbar.

try / except / finally

Python
try:
    zahl = int(input("Gib eine Zahl ein: "))
    ergebnis = 100 / zahl
    print(f"100 / {zahl} = {ergebnis}")
except ValueError:
    print("Fehler: Bitte eine gültige Zahl eingeben.")
except ZeroDivisionError:
    print("Fehler: Division durch Null ist nicht erlaubt.")
except Exception as e:
    print(f"Unbekannter Fehler: {e}")
finally:
    print("Berechnung abgeschlossen.")  # läuft IMMER

Module importieren

Python
import math
import random
from datetime import datetime

print(math.sqrt(25))      # 5.0
print(math.pi)             # 3.14159...
print(random.randint(1, 6))  # Würfelwurf
print(datetime.now())      # Aktuelles Datum/Zeit

Dateien lesen & schreiben

Python
# Datei schreiben

Best Practices für sauberen Code

  • DRY — Don't Repeat Yourself: Code duplizieren macht Wartung schwierig
  • KISS — Keep It Simple: Einfache Lösungen sind wartbarer als clevere
  • Sprechende Namen: gesamtpreis statt gp
  • Kommentiere das Warum, nicht das Was: # +1 weil Index bei 0 beginnt
  • Eine Funktion, eine Aufgabe: Kleine fokussierte Funktionen sind besser testbar
  • Konsistente Formatierung: Black (Python-Formatter) automatisch nutzen

HTML-Referenz — Die 50 wichtigsten Elemente

Jeder Eintrag enthält: Name, Syntax, Funktion, Anwendungsfall, Beispiel, häufige Fehler und Anfänger-Hinweis.

Dokumentstruktur

<!DOCTYPE html>Struktur
Syntax
<!DOCTYPE html>
Funktion
Deklariert den Dokumenttyp als HTML5 — erste Zeile jeder HTML-Datei
Anwendung
Immer als erste Zeile jeder HTML-Datei
Fehlerquelle
Fehlt DOCTYPE: Browser schaltet in Quirks-Modus mit abweichendem Verhalten
Beispiel
<!DOCTYPE html><html lang="de">...
Hinweis
Großbuchstaben bei DOCTYPE sind Konvention (nicht zwingend). Nur einmal, ganz am Anfang.
<html lang>Struktur
Syntax
<html lang="de">...</html>
Funktion
Wurzelelement des Dokuments. lang definiert die Sprache für Screenreader und SEO
Anwendung
Umschließt das gesamte HTML-Dokument
Fehlerquelle
Fehlende lang-Angabe beeinträchtigt Screenreader und Suchmaschinen
Hinweis
lang="de" für Deutsch, lang="en" für Englisch. Wichtig für Barrierefreiheit!
<meta charset>Metadaten
Syntax
<meta charset="UTF-8">
Funktion
Definiert den Zeichensatz. UTF-8 unterstützt alle Sprachen inklusive Umlaute
Fehlerquelle
Fehlt: Umlaute (ä, ö, ü) und Sonderzeichen werden falsch dargestellt
Hinweis
Immer als erstes Kind von <head>. Void element — kein schließender Tag.
<meta viewport>Responsive
Syntax
<meta name="viewport" content="width=device-width, initial-scale=1.0">
Funktion
Steuert die Darstellung auf mobilen Geräten für responsive Design
Fehlerquelle
Fehlt: Seite ist auf Smartphones winzig und nicht zoombar
Hinweis
Pflicht für jede moderne, mobile-freundliche Webseite.

Textstrukturierung

<h1> bis <h6>Text
Syntax
<h1>Hauptüberschrift</h1>
Funktion
Überschriften-Hierarchie von h1 (wichtigste) bis h6 (unwichtigste)
Anwendung
h1: Seitentitel (nur einmal!), h2: Abschnitte, h3: Unterabschnitte
Fehlerquelle
h1 mehrfach = schlechte SEO. Hierarchie überspringen (h1 → h3) = schlechte Semantik
Hinweis
Nie Überschriften für visuelles Styling nutzen — dafür CSS. Semantik vor Aussehen.
<p>Text
Syntax
<p>Absatztext.</p>
Funktion
Absatz-Element mit automatischen Abständen oben und unten
Fehlerquelle
Block-Elemente (div, h1 etc.) dürfen nicht inside <p> stehen
Hinweis
Standardelement für jeden Fließtext. Abstände per CSS steuern, nicht mit leeren <p>-Tags.
<strong> / <em>Text
Syntax
<strong>wichtig</strong> / <em>betont</em>
Funktion
strong = semantisch wichtig (fett), em = betont (kursiv)
Fehlerquelle
Nicht für rein visuelle Fettung/Kursivierung — dafür CSS (font-weight: bold)
Hinweis
strong und em haben semantische Bedeutung für Screenreader — kein Ersatz für <b>/<i>.

Links & Navigation

<a href>Navigation
Syntax
<a href="https://example.com">Linktext</a>
Funktion
Hyperlink zu einer anderen Seite, Anker oder E-Mail-Adresse
Anwendung
Navigation, externe Verweise, Downloads, E-Mail-Links
Fehlerquelle
target="_blank" ohne rel="noopener noreferrer" = Sicherheitslücke (Tabnabbing)
Beispiel
<a href="https://google.com" target="_blank" rel="noopener noreferrer">Google</a>
Hinweis
Lokale Links ohne Protokoll: href="seite.html". Anker: href="#abschnitt".

Bilder & Medien

<img>Medien
Syntax
<img src="bild.jpg" alt="Beschreibung" width="400" height="300">
Funktion
Bild einbinden — void element (kein schließender Tag)
Fehlerquelle
Fehlendes alt-Attribut = Barrierefreiheitsverletzung und schlechte SEO
Hinweis
alt="" für rein dekorative Bilder (leer aber vorhanden!). width/height angeben vermeidet Layout-Sprünge beim Laden.

Formulare

<form>Formular
Syntax
<form action="/senden" method="post">...</form>
Funktion
Container für alle Formularelemente. Definiert Ziel-URL und HTTP-Methode
Fehlerquelle
Fehlende action: Daten werden an aktuelle URL gesendet. GET statt POST: Daten in URL sichtbar!
Hinweis
method="post" für sensible Daten (Passwörter, E-Mails). method="get" nur für Suchformulare.
<input type>Formular
Wichtige Typen
text | email | password | number | checkbox | radio | file | submit | date
Fehlerquelle
Fehlendes name-Attribut: Wert wird beim Absenden nicht übermittelt!
Beispiel
<input type="email" name="email" placeholder="du@beispiel.de" required>
Hinweis
Immer mit <label for="id"> verknüpfen. required für Pflichtfelder.
<label>Formular
Syntax
<label for="email">E-Mail-Adresse:</label><input type="email" id="email">
Funktion
Beschriftung für Formularfeld. Klick auf Label aktiviert das Eingabefeld
Fehlerquelle
for-Attribut muss mit id des Inputs übereinstimmen — nicht mit name!
Hinweis
Pflicht für Barrierefreiheit. Nie Placeholder als Ersatz für Labels verwenden.

Tabellen

<table> / <tr> / <th> / <td>Tabelle
Grundstruktur
<table><thead><tr><th>Spalte</th></tr></thead><tbody><tr><td>Daten</td></tr></tbody></table>
Fehlerquelle
Tabellen für Layouts verwenden = veraltetes Anti-Pattern. Nur für tabellarische Daten!
Hinweis
thead/tbody/tfoot verbessern Semantik. colspan/rowspan für verbundene Zellen. scope="col/row" für Barrierefreiheit.

Semantische Struktur

<header> / <nav> / <main> / <footer>Semantik
header
Kopfbereich einer Seite oder eines Abschnitts
nav
Navigationsbereich. aria-label bei mehreren navs
main
Hauptinhalt der Seite — nur einmal pro Seite!
footer
Fußbereich. Nicht mit <head> verwechseln!
Hinweis
Diese Elemente machen HTML für Screenreader, SEO und Entwickler verständlicher als <div>-Suppe.
<section> / <article> / <aside>Semantik
section
Thematischer Abschnitt — braucht eine Überschrift (h2/h3)
article
Eigenständiger, wiederverwendbarer Inhalt (Blogpost, Kommentar)
aside
Ergänzender Nebeninhalt — Seitenleiste, Werbung, verwandte Links
Hinweis
Ohne Überschrift ist <div> oft besser als <section>. article könnte in einem RSS-Feed eigenständig stehen.
<details> / <summary>Interaktiv
Syntax
<details><summary>Klick mich</summary><p>Verborgener Inhalt</p></details>
Funktion
Aufklappbarer Inhalt — ganz ohne JavaScript!
Anwendung
FAQ, Zusatzinfos, Spoiler, Akkordeons
Hinweis
open-Attribut hält es standardmäßig geöffnet. summary muss erstes Kind von details sein.

Python-Referenz — Die 50 wichtigsten Elemente

Vollständige Einträge mit Syntax, Funktion, Anwendungsfall, Codebeispiel, Fehlerquellen und Anfänger-Hinweis.

Grundlegende Funktionen

print()Ausgabe
Syntax
print(wert, end="\n", sep=" ")
Funktion
Gibt einen oder mehrere Werte in der Konsole aus
Anwendung
Ausgaben anzeigen, Debugging
Fehlerquelle
Kein Zeilenumbruch: end="" setzen. Mehrere Werte: Komma trennt sie mit Leerzeichen
Beispiel
print("Hallo") | print(f"Name: {name}") | print(1, 2, 3, sep="-")

input()Eingabe
Syntax
eingabe = input("Prompt: ")
Funktion
Liest Benutzereingabe als String — IMMER als String, auch bei Zahlen!
Fehlerquelle
input() gibt str zurück → bei Zahlen int() oder float() umwandeln
Beispiel
name = input("Name: ") | alter = int(input("Alter: "))

input() wartet bis Enter gedrückt wird. Prompt-Text erklärt dem Nutzer, was erwartet wird.
len()Sequenz
Syntax
len(sequenz)
Funktion
Gibt die Anzahl der Elemente zurück — für str, list, tuple, dict, set
Fehlerquelle
len(None) wirft TypeError — vorher auf None prüfen

Syntax
range(stop) | range(start, stop) | range(start, stop, step)
Funktion
Erzeugt eine Zahlensequenz — lazy, speichereffizient
Fehlerquelle
stop ist EXKLUSIV: range(5) = 0,1,2,3,4 (nicht 5!)
Beispiel
range(5) → 0-4 | range(2,8) → 2-7 | range(0,10,2) → 0,2,4,6,8

String-Methoden

str.split() / str.join()String
split
"a,b,c".split(",") → ["a","b","c"]
join
",".join(["a","b","c"]) → "a,b,c"
Fehlerquelle
join() erwartet eine Liste von Strings — int etc. müssen erst konvertiert werden
Hinweis
split() ohne Argument trennt bei jedem Whitespace. join() ist Gegenstück von split().
str.strip() / upper() / lower()String
strip
" Hallo ".strip() → "Hallo" — entfernt Leerzeichen außen
upper/lower
"hallo".upper() → "HALLO" | "WELT".lower() → "welt"
Fehlerquelle
Strings sind immutable — strip() erstellt einen neuen String, der Original bleibt unverändert
Anwendung
strip() für Benutzereingaben bereinigen. lower() für case-insensitive Vergleiche.
str.replace() / str.find()String
replace
"Hallo Welt".replace("Welt","Python") → "Hallo Python"
find
"Hallo".find("ll") → 2 (Index) | -1 wenn nicht gefunden
Hinweis
find() gibt -1 (kein Fehler). index() gibt ValueError wenn nicht gefunden.

Listen-Methoden

list.append() / insert() / remove() / pop()Liste
append
lst.append(x) — Element ans Ende anfügen. In-place, gibt None zurück!
insert
lst.insert(0, x) — An Position einfügen
remove
lst.remove(x) — Erstes Vorkommen entfernen. ValueError wenn nicht vorhanden
pop
lst.pop() — Letztes Element entfernen UND zurückgeben
Fehlerquelle
append() gibt None zurück → nie lst = lst.append(x) schreiben!
list.sort() / sorted()Liste
sort
lst.sort() — Sortiert in-place. Gibt None zurück!
sorted
neu = sorted(lst) — Gibt neue sortierte Liste zurück. Original unverändert.
Mit key
sorted(personen, key=lambda p: p["alter"], reverse=True)
Hinweis
sort() verändert die Liste direkt. sorted() ist sicherer, weil das Original erhalten bleibt.

Dictionary-Methoden

dict.get() / keys() / values() / items()Dict
get
d.get("key", default) — Sicherer Zugriff ohne KeyError
keys

values

d["key"] wirft KeyError wenn Schlüssel fehlt → d.get("key") bevorzugen

Fehlerbehandlung
